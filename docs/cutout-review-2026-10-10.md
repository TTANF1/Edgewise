# 抠图流程复查与离线测试（2026-10-10）

本次先运行修改前基线，再实施修复并重跑同一组图片。结论是：优先保护主体细节、修复流程正确性；继续使用确定性图形学核心，不增加模型调用。

## 已实施的优化

1. **背景预处理只执行一次**。旧流程每轮把 RGB 重新构造成 RGBA，会将已有透明度恢复为 255。本次保留输入 alpha，后续仅在内存中精化边缘。
2. **所有正常退出路径保存最终输出**。修复语义质量检查提前停止时只留下临时文件的问题；回检文件由上下文管理器清理，规则模式无需临时 PNG。
3. **按实际像素变化判断收敛**。边缘数量相同不代表颜色、透明度相同。返回每轮变化像素数、停止原因和实际背景色，并提供 `--iterations` 参数。
4. **保护干净边缘和细小组件**。未触发规则的边缘保持原样；引用内部颜色时限制距离为 3 像素且必须属于同一个连通组件；无内部像素的组件保持原色。
5. **修复背景侧证据方向**。评分应为 `foreground_distance / (foreground_distance + background_distance)`，原公式方向相反。
6. **语义 KEEP 完整生效**。低污染概率的像素不再接受默认混色或局部评分加力。语义 REMOVE 加力与文档一致，叠加在基础混色上。
7. **批量混色向量化**。颜色引用统一来自本轮输入，减少逐像素 Python 循环；小尺寸图片的角落采样与中心采样不再产生空切片。

## 测试与结果

图片集：desk8 原始 8 帧、1024×1024 的手绘 favicon，以及两张可重复生成的合成图。合成图包括不透明矩形、独立小块、一像素细线；第二张加入已知的 50% 墙色污染边缘。真实图没有人工标注 alpha，不将可见像素数量当成准确率。

所有图片都成功输出透明 PNG。对代表图片生成白底、黑底、棋盘格对比；另外放大检查头发、植物、杯子蒸汽、椅子。

| 指标（通道范围 0–255） | 原流程 | 修复后默认流程 |
|---|---:|---:|
| 干净合成图前景 RGB 平均绝对误差 | 2.695 | 0 |
| 干净合成图前景 alpha 平均绝对误差 | 17.115 | 0 |
| 一像素细线逐像素保持原样 | 否 | 是 |
| 污染合成图全部前景 RGB 平均绝对误差 | 2.771 | 0.342 |
| 污染合成图全部前景 alpha 平均绝对误差 | 20.309 | 11.065 |
| 仅污染边缘 RGB 平均绝对误差 | 0.667 | 3.000 |
| desk8 半透明像素数（8 帧合计） | 9918 | 8052 |

污染边缘原始 RGB 平均误差约为 69；修复后降至 3，但略高于旧流程的 0.667。原因是旧流程对未再次触发规则的边缘继续拉色、降 alpha，新流程停止修改这些像素。这是明确的细节保护与残留清除取舍，不能宣称所有指标都改善。合成污染图以全不透明主体作为期望值，当前默认 `alpha_decay=0.40` 仍使污染像素透明度降低，因此 alpha 误差没有归零。

视觉检查：desk8 的外部背景被移除，主体结构保留，头发和植物拐角仍可见少量残留；手绘 Y 的外部白底移除，封闭内部白色区域保留。封闭白色既可能是填充也可能是背景，不能只凭颜色自动全部删除。

本次运行纯规则路径（`skip_jev=True`），13 项新增离线回归测试与原有 7 项规则/决策测试通过。语义 KEEP、提前停止与临时文件清理使用模拟 reviewer 验证，没有调用在线 Jev。虚拟环境没有 pytest，新增测试使用标准库 unittest，原有测试用其直接运行入口执行。

## 下一步的优先级

1. 建立人工标注样本：头发拐角、杯柄、蒸汽、同背景色主体、封闭白色填充和 1–3px 间隙。使用主体损失、背景残留和 alpha 误差共同评估，避免仅追求边缘变暗。
2. 区分 RGB 去污染与 alpha 重建。当前拉向内部颜色与固定 alpha 衰减仍是启发式；污染合成图的透明度误差说明两者需要独立估计。
3. 完善区域判定：UNCERTAIN 区域尚未真正交给语义层，REMOVE 当前只是 alpha 减半；区域的可达性计算也需复查（当前用不透明区域与透明背景的交集，会恒为零）。现有局部采样是邻域颜色平均，还不是真正沿法线取样。这些不应在文档中表述为已完成的区域语义闭环。
4. 语义适配器需要接收实际自动识别的背景色，按颜色与内部上下文共同去重，并记录判断；目前在线适配器仍使用初始化背景色与按 edge RGB 去重。完成以上确定性标注与接口工作后再验证在线模型增益。
